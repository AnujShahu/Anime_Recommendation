# 🎌 Anime Recommendation System

A modern, fast, and interactive **Anime Recommendation Web App** built with **Flask**, **SQLite**, and a smooth Google-like search experience.

This project allows users to:
- 🔍 Search anime by name with autocomplete
- 🎭 Browse anime by genres
- ⚡ Get instant recommendations
- 🖼 View properly scaled anime posters
- ⌨ Use keyboard navigation (Enter, Arrow keys)
- 🚀 Experience smooth UI interactions

---

## 🛠 Tech Stack

- **Backend:** Python, Flask  
- **Database:** SQLite  
- **Frontend:** HTML, CSS, JavaScript  
- **Styling:** Custom modern UI (Google-like smooth search experience)
